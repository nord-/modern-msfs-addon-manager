# Link Engine Implementation Plan (plan 1 of 6)

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** A tested, headless engine that finds the MSFS 2020 install, discovers Packages in Libraries, classifies Community, stores the user's on/off choices, reconciles against Community, applies link changes safely (deferred while the sim runs), and proposes Libraries on first run — plus a read-only `status` command to check it against the real machine.

**Architecture:** Pure domain rules in `AddonManager.Core` (no file system, no WPF), operating on records produced by `AddonManager.Infrastructure` (junctions, Community and Library reading, JSON storage) and `AddonManager.Sim2020` (install location, sim process). Core defines the interfaces (`ILinkFileSystem`, `ICommunitySource`, `IUserStateStore`, `ISimProcessMonitor`, `IFolderTree`); tests use fakes for Core and temporary folders for Infrastructure.

**Tech Stack:** C# / .NET 10 SDK, `.slnx` solution, xUnit (built-in `dotnet new xunit` template), System.Text.Json, P/Invoke for junctions, GitHub Actions on `windows-latest`.

**Spec:** `docs/superpowers/specs/2026-10-25-mvp-design.md` (sections 5, 6.1–6.3, 6.8, 7.1, 7.4, 11, 12, 13). Vocabulary: `GLOSSARY.md`.

## Global Constraints

- .NET 10 (`net10.0`, Windows-specific projects `net10.0-windows`); nothing that blocks a move to .NET 11.
- Windows only. Junctions, never symlinks, are created; no admin rights required.
- Removing a link must remove only the link (non-recursive `Directory.Delete(path, false)` on a reparse point); never delete through a link; never delete a real folder.
- Never move, modify or delete user files. Sim-managed packages, Fixed entries and Managed elsewhere Packages are never changed.
- Package names, container names and Airport codes are compared case-insensitively (`StringComparer.OrdinalIgnoreCase`).
- MSFS 2020 loads Packages only from `Official\<store>` and Community; folders in the Packages root are not Packages.
- MIT license; no code copied or translated from Dave's GSX Profile Manager (GPL-3.0).
- CRLF line endings (`.gitattributes` already declares `* text=auto eol=crlf`).
- Commit messages carry no AI attribution (user's global rule).
- User data lives in `%APPDATA%\ModernMsfsAddonManager\userdata.json`; the scan cache will live in `%LOCALAPPDATA%\ModernMsfsAddonManager\` (plan 2).

## Review Focus

1. **A Library on an unplugged drive:** discovery must report it unreachable, keep all user data, and never offer to remove its links as Broken. Plan decision: a link whose target lies under an unreachable Library is classified **Missing** (not Broken) and is ignored by reconciliation. Tests in Task 6 and Task 7.
2. **Malformed or odd `manifest.json`** (invalid JSON, UTF-8 BOM, missing `title`): the Package is still discovered and displayed by folder name. Test in Task 6.
3. **Non-ASCII and long paths** in junction targets (real: `C:\Spel\Orbx Library\msfs\EPGD Gdańsk Lech Wałęsa Airport\…`): create, read and remove must round-trip. Test in Task 3.
4. **Case differences** between a Community entry name, its target path and the Package folder name (`Asobo_C172SP_AS1000` vs `Asobo_C172sp_AS1000`): treated as the same. Tests in Task 7 and Task 10.
5. **App closed while the sim runs with pending changes:** the pending set survives and is applied exactly once on the next start when the sim isn't running. Test in Task 10.

    - `ApplyResult SetChoices(UserState state, PackageIndex index, IReadOnlyDictionary<PackageName, bool> choices)`
    - `ApplyResult Relink(UserState state, PackageIndex index, IEnumerable<PackageName> packages)` (desired = stored choices; used for RestoreApp, Moved and active-copy changes)

Planner rules per Package: locked → Rejection Locked. Desired On without an active copy → NotInLibrary. Existing entry with the same name (case-insensitive): Managed or Stale → On: Repoint if its target isn't the active copy, else nothing; Off: Remove. Any other class → On: NameTaken (`HeldBy` = its class); Off: nothing. No entry → On: Create; Off: nothing.

Applier rules:
- **Sim running:** no file-system call. Rejections are computed now (NameTaken, Locked) and not stored. Accepted choices are stored, added to `Pending`, saved once; `Deferred = true`.
- **Sim not running:** read Community, classify, plan, execute ops one by one. A Package's stored choice changes only after its op succeeded (write order: link first). Failures are reported and leave the choice as it was. Then re-read Community into `Snapshot` and save once.
- **FlushPending:** when the sim isn't running, `Relink(state.Pending)` and clear `Pending`; when it is, return `Deferred`.
- **RemoveBrokenLink:** only entries classified Broken; anything else throws `InvalidOperationException`.
